# Alien Escape

A 2D endless runner made in Unity 6. You play as an alien escaping Area 51, running across the desert while dodging obstacles and traps. Survive as long as you can for a high score.

## Controls

| Key | Action |
|---|---|
| Space | Jump (also starts and restarts the game) |
| Hold Down Arrow | Slide on the ground, or fast fall in the air |
| H | Open or close the How to Play page from the start screen |

## Tiles

| Tile | Effect |
|---|---|
| Gem | +50 points |
| Blue button | Shield that blocks the next obstacle you hit |
| Green button | Speed trap: the game runs faster for a few seconds |
| Red button | Drop trap: boxes fall from the sky ahead of you |
| Yellow pad | Launches you high. Hit it when a tall wall is coming, and jump over it when boxes hang above. Real pads and bait pads look the same. |

## How to run

Open the project in Unity 6 (6000.6), open `Assets/Scenes/_Scene_0`, and press Play.
